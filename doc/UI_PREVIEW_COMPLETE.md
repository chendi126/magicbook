## 🔧 技术实现

### 1. 颜色角色分配算法
```typescript
// 基于 HSL 色彩空间分析
- 按饱和度排序 → 选择主色、辅色
- 按亮度排序 → 选择背景色、文字色
- 按色相查找 → 选择成功色、错误色
```

### 2. 响应式更新机制
```typescript
// 使用 @State 和 @Prop 装饰器
- @State colorRoles - 父组件状态
- @Prop colorRoles - 子组件属性
- 创建新对象引用触发更新
- 使用 key 强制重新渲染
```

### 3. 组件截图和分享
```typescript
// 集成 aggregated_share 组件
- 为预览区域添加 id='uiPreviewSnapshot'
- 使用 SharePicker 进行分享
- 支持自定义海报截图
```
