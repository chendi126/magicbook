# UI 预览导出功能 - 使用指南

## 📖 功能概述

UI 预览导出功能允许你将配色方案在实际界面中的预览效果导出为图片，并支持分享到微信、QQ、微博等平台，或保存到相册。

---

## ✨ 核心功能

### 1. 导出预览为图片
- 自动截取当前预览的 UI 模板
- 生成高质量的预览图片
- 包含配色方案名称和应用信息

### 2. 多种分享方式
- 📱 **分享到社交平台** - 微信好友、朋友圈、QQ、微博
- 💾 **保存到相册** - 保存图片到本地相册
- 📋 **复制图片** - 复制到剪贴板
- 🔗 **系统分享** - 使用系统分享功能

### 3. 生成海报
- 自动生成精美的分享海报
- 包含配色方案预览和二维码
- 支持自定义海报样式

---

## 🚀 使用步骤

### 步骤 1: 选择配色方案和模板
1. 在 UI 预览页面选择一个配色方案
2. 选择想要预览的模板（卡片、按钮、列表、仪表盘）
3. 查看预览效果

### 步骤 2: 导出预览图
1. 点击底部的 **"📤 导出"** 按钮
2. 系统会自动截取预览区域
3. 进入分享/导出面板

### 步骤 3: 选择操作
在分享面板中，你可以选择：

#### 方式 1: 分享到社交平台
- 点击 **微信好友** - 分享给微信好友
- 点击 **朋友圈** - 分享到微信朋友圈
- 点击 **QQ** - 分享到 QQ
- 点击 **微博** - 分享到微博

#### 方式 2: 保存或复制
- 点击 **保存到图库** - 保存图片到相册
- 点击 **复制** - 复制图片到剪贴板
- 点击 **系统分享** - 使用系统分享功能

#### 方式 3: 生成海报
- 点击 **生成海报** - 生成精美的分享海报
- 海报包含预览图和配色信息
- 可以保存或分享海报

---

## 💡 使用技巧

### 1. 最佳预览效果
- 选择最能展示配色特点的模板
- 卡片模板适合展示整体配色
- 按钮模板适合展示主色和辅色
- 列表模板适合展示层次感
- 仪表盘模板适合展示数据可视化

### 2. 分享给客户
- 使用"生成海报"功能创建专业的展示图
- 海报包含配色方案名称和应用信息
- 适合向客户展示设计方案

### 3. 保存到相册
- 建立自己的配色效果图库
- 方便后续查看和对比
- 可以用于设计文档和汇报

### 4. 快速分享
- 使用"系统分享"可以分享到更多应用
- 支持通过蓝牙、NFC 等方式分享
- 支持碰一碰分享（需要设备支持）

## 🔧 技术实现

### 集成的组件
- **aggregated_share** - 华为官方分享组件
- 支持微信、QQ、微博等主流平台
- 支持生成海报、保存图库等功能

### 截图机制
- 使用组件 ID 标识截图区域
- 自动截取预览区域的内容
- 生成高质量的图片

### 分享数据
```typescript
{
  title: '${配色方案名称} - UI 预览',
  subTitle: '拾色师配色设计',
  createTime: Date.now(),
}
```

---

## ⚙️ 配置说明

### 分享选项
```typescript
{
  extComponentId: 'uiPreviewSnapshot',  // 截图区域 ID
  directPoster: true,                   // 直接打开海报面板
  posterSheetTitle: '导出预览图',       // 海报面板标题
}
```

### 自定义配置
你可以在代码中修改以下配置：
- 海报标题和副标题
- 截图区域的样式
- 分享面板的选项

## 📋 注意事项

### 权限要求
- **网络权限** - 分享到社交平台需要网络
- **存储权限** - 保存到相册需要存储权限

### 平台配置
如果需要分享到微信、QQ、微博，需要：
1. 在对应平台申请 AppID
2. 在 `EntryAbility.ets` 中配置 SDK
3. 在 `module.json5` 中添加配置

详细配置请参考：`ohos_agcit/agcit_huawei_common_share/aggregated_share/README.md`

### 使用限制
- 截图功能需要在真机上测试
- 某些模拟器可能不支持截图
- 分享到第三方平台需要安装对应应用
