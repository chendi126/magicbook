# 🎨 UI 设计预览功能 - 使用指南

## 📖 功能概述

UI 设计预览功能让你可以在实际的移动应用界面模板中查看配色方案的应用效果，并生成可复用的 ArkTS 组件代码。

---

## ✨ 核心功能

### 1. 配色方案预览
- 从配色库中选择任意配色方案
- 实时预览配色在不同 UI 模板中的效果
- 智能分配颜色角色（主色、辅色、背景等）

### 2. 多种 UI 模板
- **📇 卡片模板** - 展示信息卡片、统计数据、操作按钮
- **🔘 按钮模板** - 展示主要按钮、轮廓按钮、文字按钮、状态按钮
- **📋 列表模板** - 展示列表项、色条标识、箭头指示
- **📊 仪表盘模板** - 展示统计卡片、数据展示

### 3. 组件代码生成
- 一键生成 ArkTS 组件代码
- 自动应用配色方案
- 支持复制到剪贴板
- 可直接粘贴到项目中使用

---

## 🚀 使用步骤

### 步骤 1: 进入设计预览页面
1. 打开应用
2. 点击底部导航栏的 **"设计"** 标签

### 步骤 2: 选择配色方案
1. 在顶部横向滚动查看所有配色方案
2. 点击任意配色方案卡片进行选择
3. 选中的方案会显示蓝色边框

### 步骤 3: 选择 UI 模板
1. 在模板选择器中点击想要预览的模板
   - 📇 卡片
   - 🔘 按钮
   - 📋 列表
   - 📊 仪表盘
2. 预览区域会实时更新显示效果

### 步骤 4: 生成组件代码
1. 点击底部的 **"生成代码"** 按钮
2. 查看生成的 ArkTS 组件代码
3. 点击 **"复制代码"** 按钮复制到剪贴板
4. 粘贴到你的项目中使用

## 🎨 颜色角色分配

系统会智能分配配色方案中的颜色到不同的 UI 角色：

| 角色 | 说明 | 分配逻辑 |
|------|------|----------|
| **主色** | 主要按钮、重要元素 | 选择饱和度最高的颜色 |
| **辅色** | 次要按钮、辅助元素 | 选择第二饱和的颜色 |
| **背景色** | 页面背景 | 使用最亮的颜色或白色 |
| **表面色** | 卡片、对话框背景 | 使用次亮的颜色或浅灰色 |
| **文字色** | 主要文字 | 使用最暗的颜色或深灰色 |
| **强调色** | 高亮、提示 | 选择第三个颜色或主色变体 |
| **成功色** | 成功提示 | 绿色系或默认绿色 |
| **错误色** | 错误提示 | 红色系或默认红色 |

## 📝 生成的代码示例

### 卡片组件示例

```typescript
/**
 * 夏日海滩 - 卡片组件
 * 自动生成的配色方案应用示例
 */

@Component
export struct SummerBeachCard {
  title: string = '精选推荐';
  description: string = '发现更多有趣的功能和特性';
  
  build() {
    Column() {
      // 卡片头部
      Column() {
        Text(this.title)
          .fontSize(20)
          .fontWeight(FontWeight.Bold)
          .fontColor('#FFFFFF')
      }
      .width('100%')
      .height(120)
      .padding(16)
      .backgroundColor('#FF6B6B')
      .borderRadius({ topLeft: 16, topRight: 16 })
      .justifyContent(FlexAlign.End)

      // 卡片内容
      Column() {
        Text(this.description)
          .fontSize(14)
          .fontColor('#666666')
          .margin({ bottom: 16 })

        // 操作按钮
        Row() {
          Button('查看详情')
            .fontSize(15)
            .fontColor('#FFFFFF')
            .backgroundColor('#FF6B6B')
            .borderRadius(20)
            .layoutWeight(1)
            .height(44)

          Button('分享')
            .fontSize(15)
            .fontColor('#5856D6')
            .backgroundColor('#F5F5F5')
            .borderRadius(20)
            .layoutWeight(1)
            .height(44)
            .margin({ left: 8 })
        }
        .width('100%')
      }
      .width('100%')
      .padding(16)
      .backgroundColor('#F5F5F5')
      .borderRadius({ bottomLeft: 16, bottomRight: 16 })
    }
    .width('100%')
    .borderRadius(16)
    .shadow({ radius: 12, color: 'rgba(0, 0, 0, 0.1)', offsetY: 4 })
  }
}
```

## 💡 使用技巧

### 1. 快速对比配色效果
- 在同一个模板下切换不同的配色方案
- 观察哪个配色方案在该场景下效果最好

### 2. 测试不同场景
- 同一个配色方案在不同模板下的效果可能不同
- 建议在多个模板中预览，确保配色的通用性

### 3. 代码复用
- 生成的代码可以直接使用
- 也可以作为参考，根据实际需求调整

### 4. 配色优化
- 如果预览效果不理想，可以返回"实验室"调整配色
- 或使用"配色库"中的颜色调整功能

## 📊 技术实现

### 核心组件
- **UIPreviewPage.ets** - 主页面
- **MobileUITemplates.ets** - UI 模板组件
- **ColorRoleMapper.ets** - 颜色角色分配
- **UICodeGenerator.ets** - 代码生成器

### 智能算法
- 基于 HSL 色彩空间分析颜色特征
- 按亮度、饱和度、色相智能分配角色
- 自动生成和谐的配色组合
